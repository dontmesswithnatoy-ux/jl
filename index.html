// 04. Analytical Thinking

Problem Solving

How I approach common development challenges and work toward practical, reliable solutions.

🔍
STEP 01

Identify the Problem

I identify what is not working as expected, review requirements, observe the problem, and determine which part of the system needs attention.

🧩
STEP 02

Analyze Possible Causes

I check the related code, user inputs, database records, and system behavior. Breaking a large issue into smaller parts helps me find possible causes.

🛠️
STEP 03

Develop a Solution

I try a suitable solution, keep code organized, validate inputs, and make changes without unnecessarily affecting other features.

✅
STEP 04

Test and Improve

I test the updated feature, check different inputs, and correct remaining errors to make the application more dependable and easier to use.

Examples From My Projects

  • Food Ordering System: Organizing menu information and checking order inputs to help reduce incorrect order details.
  • Hotel Booking System: Organizing customer and reservation records while checking room availability.
  • Arduino Water Dispenser: Checking sensor readings and output behavior to improve automatic dispensing.

// 06. Personal Growth

My Reflection

Lessons I have learned as an Information Technology student while working on academic projects.

💭

As an Information Technology student, I have learned that developing a system requires more than writing code. It also requires planning, patience, testing, and understanding the needs of the people who will use the application.

Working on web development projects helped me understand how different parts of a website work together. I learned that the interface should be clear and easy to navigate, while the system logic and database should handle information properly. Even small errors can affect how users experience an application.

My database project helped me appreciate the importance of organizing information and checking data carefully. My Arduino project also showed me that hardware and software must work together correctly. Testing the system and checking its behavior are important parts of development.

I also realized that problem solving takes time. When a feature does not work, I need to review the code, identify possible causes, and test different solutions instead of making random changes. Asking for feedback and learning from mistakes can help me improve my work.

Moving forward, I want to strengthen my programming skills, learn more development tools, and gain experience working on real projects. These experiences motivate me to continue learning and prepare for a future career in the IT industry.
